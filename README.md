# WashHub Counter Dashboard

WashHub is reworking the desktop dashboard used all day by counter staff in its laundromat stores to monitor the floor, manage active orders, and move customers through pickup quickly. Today, the browser design editor contains three current-state React-backed screens: Store overview, Order queue, and Order detail. The team wants the experience to help staff understand the store state at a glance, spot exceptions before they cause delays, and recognize the next meaningful action on an order without slowing down counter work. Rework the three screens in the design editor toward those goals, then update the matching React starter project so the implemented screens reflect your revised design.

## Objectives

- Make the state of the laundry floor readable at a glance.
- Surface overdue, unpaid, out-of-order, and other exception states without hunting.
- Make the next action on an order obvious and easy to act on.
- Keep the redesigned experience coherent across Store overview, Order queue, and Order detail.
- Update the React implementation so it accurately matches the revised design.

## What you are given

- The current design, open in your Utkrusht design workspace (see `design/preview.png` for a snapshot).
- A matching React starter project in this repository.
